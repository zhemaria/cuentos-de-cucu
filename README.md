# Los cuentos de Cucu

Cuentos ilustrados y narrados por José M. Fernández (Cucu) para sus biznietos.

Se leen en: https://zhemaria.github.io/cuentos-de-cucu/

Cada cuento vive en su propia carpeta (`israel-y-su-hermanito/`, …) con:

- `index.html` — el libro; el texto está en el objeto `LIBRO`
- `images/` — portada, láminas y avatar
- `audio/` — la narración de cada página
- `video/` — videos y sus pósteres (`video/poster/`)

Para un cuento nuevo: copiar la carpeta de un cuento, cambiar `LIBRO` y añadirlo al estante de `index.html`.
